# 分子ラボ3D

化学基礎の授業で使える、**分子・イオン・結晶を立体で回して見る**Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/chemistry-simulator/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 左の一覧から分子をえらぶ（または検索欄に分子式・名前を入力）
3. 立体モデルを **ドラッグで回転**、**ホイール／ピンチで拡大**、**原子をクリック** するとその原子の詳しい情報

> 立体表示の部品（three.js）とフォントはインターネットから読み込みます。授業で使うときはネットにつながった状態で開いてください。

## できること

| 機能 | 内容 |
|---|---|
| 表示のしかた | **球棒**（結合が見やすい）／**空間充填**（実際の大きさ・すき間）／**棒** |
| 非共有電子対 | 紫のふくらみ＋電子2個で表示。水が折れ線形になる理由が見える |
| 結合角 | 中心原子のまわりの角度を弧と数字で表示（水 104.5°、メタン 109.5° など） |
| 極性 | 電子が集まる側を赤（δ−）、少ない側を青（δ+）で色分け。分子全体のかたよりを矢印で表示 |
| 熱運動 | 原子がふるえる様子のイメージ |
| 全画面 | プロジェクターに映すとき用 |
| 解説 | 分子量（計算式つき）・形・極性・共有電子対／非共有電子対の数・結合の種類と本数・性質・授業のポイント |
| 異性体・同素体 | 同じ分子式の物質（エタノールとジメチルエーテルなど）へすぐ切りかえ |

## 画面の構成（シンプルに整理）

- 画面上は **見る／動かす／挑戦／授業モード** の4つだけ。
  - 見る：分子・くらべる・結晶・原子と電子・結合
  - 動かす：状態変化・pH・反応式・mol・つくる
  - 挑戦：タイムアタック・クイズ
  - 授業モード：大きな文字で1画面ずつ進む授業用スライド
- 説明カードは「ポイント」「くわしく」の2つのタブに分けたので、スクロールせずに要点が見える。
- 「特徴でさがす」はふだん閉じておき、押したときだけ開く。

## 新しい体験

- **pH のものさし**：pH 0〜14 のスライダーと、胃液・レモン汁・血液・せっけん水など14種類の身近な液体。ビーカーの中の H₃O⁺（赤）と OH⁻（青）の数が変わり、BTB・フェノールフタレイン・万能試験液の色に変わる。
- **中和チャレンジ**：0.10 mol/L の塩酸（または硫酸）10 mL に、NaOH を＋5 mL・＋1 mL・＋1滴で加えて、BTB を緑にするゲーム。中和の曲線（pH のグラフ）がその場でかかれる。硫酸では2倍の量が必要なことも体験できる。
- **タイムアタック**：60秒で、3Dの分子を見て名前・分子式・形・極性などに答える。自己ベストを記録。
- **物質の分離**（動かす）：混合物・蒸留・ろ過・再結晶・昇華法・抽出・ペーパークロマトグラフィー・炎色反応を、分子やイオンが動くようすで見る（くり返し再生）。
- **化学**（動かす）：気液平衡と蒸気圧・ボイルの法則・シャルルの法則・溶解と水和・浸透圧・コロイドとチンダル現象・ダニエル電池・反応の速さと温度・化学平衡（N₂O₄ ⇄ 2NO₂）・付加重合を、粒子が動くようすで見る。
- **授業モード**：「化学基礎」24 の授業と「化学」27 の授業（合計 209 画面）。メニュー上のタブで科目を切りかえる。学習指導要領の順に並ぶ。左の一覧が消えて大きな文字になり、「次へ」やキーボードの ← → で進む。
  - 第1編 物質の構成：1-1 純物質と混合物・物質の分離／1-2 単体と化合物・同素体／1-3 物質の三態と熱運動／2-1 原子の構造と同位体／2-2 電子配置と周期表／2-3 イオンのでき方／3-1 イオン結合とイオン結晶／3-2 共有結合と分子／3-3 分子の形／3-4 電気陰性度と極性／3-5 分子間力と水素結合／3-6 共有結合の結晶・分子結晶／3-7 金属結合と金属
  - 第2編 物質の変化とその利用：4-1 原子量・分子量・式量／4-2 物質量／4-3 溶液の濃度／4-4 化学反応式のつくり方／4-5 化学反応式と量的関係／5-1 酸と塩基／5-2 水素イオン濃度と pH／5-3 中和反応と塩／6-1 酸化と還元／6-2 金属のイオン化傾向／6-3 酸化還元と私たちの生活
  - 実験に関係する画面には「実験ラボでやってみる」ボタンがあり、実験ラボのその実験が別タブで開く。
  - 化学：化1-1 状態変化と蒸気圧／化1-2 気体の法則／化1-3 固体の構造／化1-4 理想気体と実在気体／化4-4 溶解度積／化5-3 気体の製法／化5-4 金属イオンの分離／化5-5 セラミックス・金属／化6-4 油脂とセッケン／化6-5 フェノール類／化6-6 窒素をふくむ芳香族／化6-7 有機化合物の分離と構造決定／化7-3 プラスチック・ゴム・機能性高分子／化2-1 溶解と溶解度／化2-2 希薄溶液の性質とコロイド／化3-1 化学反応と熱／化3-2 電池と電気分解／化4-1 化学反応の速さ／化4-2 化学平衡と平衡の移動／化4-3 電離平衡と緩衝液／化5-1 非金属元素／化5-2 金属元素／化6-1 炭化水素／化6-2 酸素をふくむ有機化合物／化6-3 芳香族化合物／化7-1 合成高分子／化7-2 天然高分子

  - 確認テスト：各授業に4問（全204問）。「テストをとばす」でスキップして次の授業へ進める。授業の最後の「確認テストへ」か、メニューの「テスト」ボタンから。3問以上正解で合格して 🏅 がつき、「合格した授業 ○ / 24」がたまっていく。合格すると「次の授業 →」。
  - 授業の最後に「次の授業 →」。見終わった授業には ✓ がつき、メニューの「続きから」で次の授業を始められる。

## 分子の特徴を体感する

- **状態変化**：温度のスライダー（−200〜250 ℃）を動かすと、27個の分子が「固体（その場でふるえる）→液体（動き回る）→気体（飛び回る）」と変わる。融点・沸点の目盛りつき。水・硫化水素・エタノール・ジメチルエーテル・メタン・アンモニア・二酸化炭素（昇華）・酢酸・ブタン・ベンゼン。水素結合は青い点線で表示され、沸点が高くなる理由が見える。
- **くらべる**：2つの物質を並べて表示し、ちがう項目に色をつけた比較表を出す（15組：水と硫化水素、エタノールとジメチルエーテル、CO₂ と SO₂、ダイヤモンドと黒鉛 など）。
- **特徴タグ**：それぞれの物質に「気体／液体／固体」「水素結合」「極性分子」「燃える」「酸性」「塩基性」「水に溶けやすい」「注意が必要」などのタグ。タグを押すと、同じ特徴の物質の一覧になる。

## 自分で操作して学ぶ

- **化学反応式**：20種類の反応（中和・亜鉛と塩酸・貝がらと塩酸・重曹の熱分解・鉄と硫黄・酸化銅の還元を追加）（水素の燃焼・メタンの燃焼・光合成など）。＋／−で係数を変えると、3Dの分子の数と「左右の原子の数」の表がその場で変わる。つり合ったら「反応させる」で、左の原子が1個ずつ右の分子へ移動する（原子の種類と数が変わらないことが見える）。ヒントつき。クリアした反応式には ✓。
- **分子をつくる**：原子（H・C・N・O・Cl）を手（価標）の数に合わせてつなぎ、分子を完成させるミッション。二重結合・三重結合もつくれる。できた分子が一覧にあれば名前を表示。「C₂H₆O を2種類」「C₄H₁₀ を2種類」で異性体も体験できる。
- **クイズ**：1回10問（常温の状態・水素結合・沸点くらべの問題も追加）。分子の形・極性・分子式・分子量・電子配置・価電子・イオン・結合の種類・mol計算・反応式の係数。答えると3Dの模型と説明で確認できる。最高点を記録。

## 画面の使い方

- 画面上の **分子／結晶／原子と電子／結合のしくみ／物質量（mol）** で分野を切りかえます。
- 表示の切りかえ（結合の色分け・電子対・電子雲・結合角・極性・回転など）は、3D画面左上の **「表示」** ボタンにまとめてあります。
- 結晶では **「単位格子／2×2×2／3×3×3」** で、単位格子をたくさん並べた状態を見られます（青い箱がまん中の単位格子）。
- 原子は周期表の形でえらべます。**「電子殻モデル／電子雲」** で電子の表し方を切りかえられます。
- **物質量（mol）**：物質と、物質量・質量・粒子の数・気体の体積のどれかを入力すると、ほかの量を計算式つきで表示。3Dでは「模型1個 = 0.1 mol」の粒子のかたまり、はかりの上の質量、実際の体積の箱（1 L の箱とくらべる）が変化します。

## 新しく加わった機能

- **説明カードがモデルの画面の中に**：分子の形・極性・結合角・性質・授業のポイントが、スクロールしなくても立体モデルの横（スマホでは下）に出ます。右上の ∨ ボタンでたためます。
- **結合の種類が色でわかる**：単結合（灰）・二重結合（青緑）・三重結合（紫）・配位結合（オレンジ）・イオン結合（ピンクの点線）・水素結合（青の点線）・自由電子（黄色の粒）。画面左下に凡例と本数が出ます。
- **共有電子対**：ONにすると、すべての結合の上に電子2個ずつ（黄色の粒）が表示され、二重結合なら4個、三重結合なら6個とわかります。
- **原子と電子殻**：原子番号1〜20の原子を、原子核（陽子・中性子）と K殻・L殻・M殻・N殻を回る電子で表示。「陽イオンにする／陰イオンにする」ボタンで、電子が出ていく・入ってくる様子と、貴ガスと同じ電子配置になることを確かめられます。
- **結合のしくみ（アニメーション）**：共有結合のでき方（H₂）、イオン結合のでき方（Na と Cl の間で電子が移る）、金属結合（自由電子）、配位結合のでき方（NH₃ + H⁺）、水素結合（水分子5個）。再生・一時停止・スライダーで好きな場面に止められます。

## 分子式の入力

- `H2O`、`C2H6O`、`CO(NH2)2`、`NH4+`、`SO4^2-`、`CuSO4·5H2O` などの書き方が使えます。
- 一覧にある物質はそのまま表示します。同じ分子式の物質が複数あるときは全部出します。
- 一覧にない分子式（例：`C3H6`、`HCN`、`C3H8O`）は、**価標（手の数：H 1本、O 2本、N 3本、C 4本）が合うように自動で組み立てて**立体表示します。異性体がある場合はその一例です。
- どんな分子式でも分子量（式量）は計算します。

## しくみ（先生向けメモ）

- 立体の形は **VSEPR（電子対反発）の考え方** で計算しています。共有電子対と非共有電子対を「おたがいに反発するもの」として、最も離れる向きを探しています（非共有電子対の反発を少し強くしてあるので、水は約104.5°、アンモニアは約107°になります）。
- 極性は電気陰性度（ポーリングの値）の差から求めています。化学基礎の扱いに合わせて、C–H結合の極性は無視しています。
- 実際の分子とは細かい数値がずれることがあります（例：硫化水素の実際の結合角は約92°）。
- URLの最後に `#ethanol` のように付けると、その分子を開いた状態のリンクになります（ID は `index.html` の一覧 `LIB` を参照）。

### ⏱ タイムアタック（ひとりで）
- 時間内に、分子の形・極性・電子配置・イオン・分子量・mol 計算・係数・状態・水素結合・沸点くらべ などに答えます。
- **出題範囲**：「分野で選ぶ」（ミックス／形・結合／原子・イオン／計算／物質の特徴）か、「**単元で選ぶ**」（授業モードの化学基礎 24 単元・化学 27 単元から、1 つずつえらぶ／「最初 〜 ○○ まで」でまとめてえらぶ）。単元では、その単元の確認テストの問題と、数字が毎回かわる問題・計算問題（4 択）が出ます。
- **時間**：30 秒・1 分・1 分 30 秒・2 分・3 分・5 分。
- **表示**：問題といっしょに出すものを えらべます。「図」＝分子の構造図・原子の電子殻の図、「3D」＝くるくる回る模型、「式」＝問題文の化学式（オフにすると物質名だけ。反応式の問題や、確認テストの問題文に元から入っている式は残ります）。電子配置を問う問題では、答えになってしまうので図は出しません。
- 続けて正解すると **コンボ**。10 コンボごとに 点数が ×1.5 → ×2 → … → ×3。
- 結果は「17 問正解 ≒ 共通テスト化学基礎 1 回分の問題数」のように出ます。「📣 自慢する」で結果の文章をコピー。

## 実験ラボ3D（別ページ：`lab.html`）

化学の実験器具を3Dで見て、使い方を練習するページ。分子ラボ3D の右上「実験ラボ（器具）」から別のタブで開く。

- **器具を見る**（12種類）：ビーカー・三角フラスコ・丸底フラスコ・試験管・ろうと／メスシリンダー・ホールピペット・ビュレット・こまごめピペット／アルコールランプ・ガスバーナー・蒸発皿。回して見られ、部分の名前つき。「何に使う？」「使い方」「注意（○×）」のタブ。
  - 「さわってみる」タブ：アルコールランプ（ふたをとる・横から点火・ふたで消す。息で吹き消すと注意）、ガスバーナー（2つのねじで炎の色が変わる。空気が多すぎると消える・火なしでガスを出し続けると警告）、ビーカー・三角フラスコ・丸底フラスコ・試験管・メスシリンダー・蒸発皿（純水・うすい塩酸・水酸化ナトリウム水溶液・食塩水・硫酸銅(II)水溶液・BTB・フェノールフタレインを入れて、色・pH・沈殿を見る。加熱して沸騰・蒸発させると、とけていた物質が残る）、ビュレット（コックを開いて中和点で赤くなる）、ろうと（水を注ぐ）。
- **操作の練習**（6種類）
  - ガスバーナーに火をつける：ねじの確認 → 元栓・コック → マッチ → ガス調節ねじ → 空気調節ねじ。手順のチェックリストつき。空気の量で炎がオレンジ色から青色に変わる。順番をまちがえると警告。
  - アルコールランプ：アルコールの量・芯の長さ・横から点火・ふたで消す。「息で吹き消す」などのまちがった操作を押すと理由が出る。
  - メスシリンダーを読む：上から／真横から／下から見て、0.1 mL まで読む練習問題。
  - ろ過の準備：ろ紙をぬらす・ろうとの先をかべにつける・ガラス棒を使う・8分目まで。
  - 試験管を加熱する：口の向き・試験管ばさみの位置・ふりながら加熱・液の量。
  - 電子てんびんの使い方：水平の確認・薬包紙・ゼロ（風袋）ボタン・薬さじで少しずつ。5.00 g ちょうどをはかる。
- **実験**（14種類）
  - 気体の集め方：H₂・O₂・CO₂・NH₃・HCl・Cl₂・N₂ を、水上置換・上方置換・下方置換で集める。まちがった方法だと気体がにげる・こぼれる・水に溶けて逆流する様子が見える。
  - 水の電気分解：ホフマン型装置。水酸化ナトリウムの有無、電圧、気体の体積（2：1）、マッチ・線香での確認。
  - 炎色反応：白金線を炎に入れて Li・Na・K・Cu・Ca・Sr・Ba の色を見る。なぞの水溶液の当てっこつき。
  - 中和滴定：ビュレットから NaOH を1滴ずつ落とし、フェノールフタレインが赤くなった終点から塩酸の濃度を計算する。
  - 蒸留：温度計の位置・沸騰石・冷却水の向き・液の量・受け器を正しく組んでワインからエタノールを取り出す。
  - 銅の酸化：銅の粉を何度も加熱して質量をはかり、増えなくなるまで続ける。銅と酸化銅の質量のグラフ（4：5）をつくる。
  - 再結晶：温度を上げ下げして硝酸カリウムの結晶を取り出す。溶解度曲線つき。不純物の塩化ナトリウムは溶けたまま残る。
  - 金属のイオン化傾向：Mg・Zn・Fe・Cu・Ag の板を、硫酸銅・硝酸銀・硫酸亜鉛・塩酸にひたして、金属が出てくるか・あわが出るかを見る。
  - 鉄と硫黄の反応：混合物の上部を加熱し、火を止めても反応が進む様子（発熱反応）を見る。反応の前後で磁石・塩酸の反応をくらべる。
  - 気体の発生装置：ふたまた試験管（傾けて反応を始める・止める）とキップの装置（コックで調節）。
  - 手順トレーニング型（「次にすることは？」を3択で選んで進める。まちがえると理由が出る）
    - 決まった濃度の溶液をつくる（メスフラスコで 0.100 mol/L NaCl を 100 mL）
    - 炭酸水素ナトリウムの熱分解（口を下げる・石灰水・塩化コバルト紙・誘導管を抜いてから火を消す）
    - ペーパークロマトグラフィー（鉛筆の線・小さな点・液面は線より下・ふた・溶媒前線）
    - 昇華法（ヨウ素と砂の混合物から、冷たいフラスコでヨウ素を取り出す）
- **クイズ**：器具の名前あて、安全な使い方 ○×（各10問、実験の問題も追加）。
- 操作の練習には「やってみる／手順とわけ／注意」の3つのタブ。
  - 手順とわけ：手順をタップすると「なぜ？」が開く。「ならべかえチャレンジ」で手順の順番を覚えられる（全20種類）。
  - 注意：ミスしやすい点と、危険・安全のためのことをまとめて表示。
- 画面の構成：左に分類（基本操作・溶液・中和・気体・分離・精製・物質の変化・電気・イオン）、まん中に3Dの実験台、右に説明パネル。説明パネルが3Dに重ならないので、器具が隠れない。スマホでは 3D → 説明 の順にたてに並ぶ。
- 上のバーは「器具／操作／クイズ」の切りかえと、分子ラボ3Dへの小さなボタンだけ。
- 3Dの見方：ドラッグで回転、右ドラッグ・Shift＋ドラッグ・2本指で平行移動。右上の「移動」ボタンを押すと、ふつうのドラッグ（1本指）で平行移動になる。ホイール・ピンチは、カーソル（指）のある所に向かって拡大・縮小する。「向きをもどす」は実験の進み具合をそのままに、見る位置だけもどす。
- 部分の名前は、器具の左右の空いている所に並べて、線で指す（器具に重ならない）。「部分の名前」ボタンで消すこともできる。
- 説明が長いときも、「加熱する」などのメインの操作ボタンはパネルの下に出たままになる。スマホでは画面全体がスクロールせず、説明パネルの中だけが動く。
- 器具を見るには「この形のわけ」。
- 3Dモデル：ガラスの厚み・周囲の映りこみ・器具の下の影・ローレットつき調節ねじ・ガラス棒など、実物に近い形に改良。

## 原子と電子（全118元素）

- 周期表（1〜18族・第1〜7周期、ランタノイド・アクチノイドの行つき）から全118元素をえらべる。分類ごとに色分け（アルカリ金属・アルカリ土類金属・遷移元素・ハロゲン・貴ガスなど）。化学基礎の範囲（1〜20番）は太わく。
- 電子殻は K〜Q殻 の7つまで。実際の電子配置（Cr・Cu・Ag・Au・Pd・Pt・ランタノイドなどの例外もふくむ）で表示し、くわしい電子配置（[Ar] 3d⁵ 4s¹ など）も見られる。
- 族・周期・典型／遷移・金属／非金属・常温の状態・原子量・中性子の数を表示。
- Fe²⁺・Cu²⁺・Zn²⁺・Ag⁺・Br⁻・I⁻ などのイオンにもできる（外側の殻から電子を失う）。
